Задание 1. int coldDelivery(int kilometers, int rate, int coldBoxes): km·rate + boxes·7; все данные неотрицательны, иначе -1.

Задание 2. bool loadBoxes(int& emptySlots, int boxes): при boxes > 0 и достаточном месте уменьшить emptySlots.

Задание 3. Перегрузите routeCost: int routeCost(int km, int rate) — km·rate; int routeCost(int km, int rate, int urgentFee) — добавить urgentFee. При отрицательных аргументах -1.

Задание 4. int foodDelivery(int distance, int perKm = 3, int minimum = 12): вернуть max(distance·perKm, minimum), если данные неотрицательны.
